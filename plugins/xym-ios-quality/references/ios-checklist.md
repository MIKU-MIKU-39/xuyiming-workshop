# Xuyiming：跨项目 iOS 检查清单

以下是问题提示，不是固定技术栈或强制阈值。只检查和本次变更相关的项。

## API 与兼容性

- 当前依赖版本是否确实公开该 API？部署版本、availability、Swift/ObjC 桥接、nullability 是否一致？
- 公开类型、枚举值、序列化字段是否有外部消费者？是否需要兼容旧数据和二进制？
- 错误/取消/超时是否有明确出口？空数据、越界、重复回调与部分成功是否处理？

## 生命周期与线程

- block、delegate、timer、observer、task、notification 是否形成持有环，是否需要取消与释放？
- UI 是否在主线程；共享状态读写是否在同一隔离域？actor/MainActor 迁移是否影响调用方？
- 锁内回调、同步派发、嵌套等待是否可能死锁？重入和取消是否破坏状态机？
- weak 捕获是否会让必要操作静默丢失？unowned 和强制解包是否有足够生命周期证据？

## 资源与性能

- 图片解码、JSON、数据库、I/O 是否阻塞交互？缓存是否有边界和正确的失效策略？
- cell 复用、异步图片、分页请求是否有串位、重复加载或过期响应问题？
- 观察者、句柄、临时文件与后台任务是否按路径释放？部分初始化失败是否清理？

## 项目一致性与验证

- 先用已有组件与模式；布局库、命名、日志、文件头、行宽和语言版本以项目配置为准。
- 术语检查是项目静态规则，不等于审核合规保证；生成代码应修正生成源。
- 测试覆盖成功、失败、取消、重复执行和边界；原始日志/xcresult 与口头结论是否一致？
- 确认用户未提交改动被保留；只读评审不修改代码，未经授权不提交/推送。
