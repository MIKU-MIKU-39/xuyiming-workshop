# 组件复用

先确认 selection / implementation / review / migration 模式及用户授权范围。默认使用本地证据：Podfile.lock、Package.resolved、podspec、Package.swift、公开头文件、模块接口和 Example/Tests；不依赖公司 MCP。

- 按需求拆出必要能力和约束：最低系统版本、线程、可见性、二进制/源码分发、依赖体积、许可证。
- 使用 rg 检索相似实现和真实调用方。只读搜到的名字不能证明 API 公开或版本可用，要查当前锁定版本。
- 外部组件索引/MCP 仅在项目有已配置且获授权的 provider 时使用；缺少时继续本地搜索，不报成必须安装公司服务。
- 输出候选表：能力、API 证据文件/行号、限制、采用/排除理由。找不到足够证据时写“待核实”，不是强行推荐。
- 实现只复用实际存在的接口；迁移先列调用方与兼容面，再局部替换并回归。review 模式不修改。
- 不把业务命名前缀当成通用组件类别，不因公司项目曾使用某组件而自动给其他项目加依赖。
