# 提炼项目经验

先确认材料与目标：当前任务、指定 commit 范围或特定模块，以及输出为项目文档还是 Skill 草稿。只读取用户放入范围内的对话和仓库；不扫描其他任务私密记录。

每个候选模式包含：问题、触发条件、有效做法、代码/commit 证据、反例、适用边界、如何验证。单次巧合标记为假设，多次独立证据才提高可信度；不把信心分数当客观统计。
合并已有同义规则；项目特有约定留在项目，不升级成全局行为。不得自动删除旧规则、读取凭据或把内部业务信息推送到外部仓库。
写文件前确认路径和范围；只要求建议时输出草稿。需要形成可安装技能时遵守宿主现有 skill-creator 规范；没有该技能时最小目录 skills/name/SKILL.md，含 name/description、工作流、边界和可核验例子。
制作后用正例、边界例、负例检查触发与结果；说明哪些尚未在真实任务中验证，不自动安装、发布或推送。
