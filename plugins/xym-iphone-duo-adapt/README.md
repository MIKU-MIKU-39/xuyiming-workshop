# Xym iPhone Duo Adapt

Created by Xuyiming on 2026/10/29.

最小侵入适配 iPhone Duo，保持普通 iPhone 原有视觉。覆盖基础/二级页面、列表、按钮、系统栏与 ReservedRegion，不附带重写、防护框架或业务修复。PPT 和 Apple 官方资料的结论已整理在技能参考中，原资料无需随插件安装。

每修正 1–3 个页面，主 Agent 必须派发独立子 Agent 做只读代码审核与 Duo/普通 iPhone 模拟器 UI 回归；保存同条件前后截图与交互证据，修复后复验，通过再进入下一批。缺设备、基线或操作能力会报告阻塞，不以编译成功替代 UI 通过。大屏允许必要重排，不允许任意更改颜色、间距、大小或圆角。

调用示例：

```text
使用 $xym-iphone-duo-adapt 适配 /实际工程路径 的直播列表和二级详情，保持原 UI。
```

技能先核实工程、页面入口和模拟器条件，不默认提交/推送业务代码、发布组件或改变全局工具链。配套资源仅包含技能说明、来源、回归协议与证据模板，复用项目现有工具。
