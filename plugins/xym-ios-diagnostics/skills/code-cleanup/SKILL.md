# 无用代码审计

确认模式：Model 字段 / 方法和符号 / 文件资源 / 指定范围全量。先读项目 target、源码分发边界和依赖者；引用扫描使用本插件 scripts/reference_scan.py，详细行为见本插件 symbol-references 技能。

检查证据链：定义 → 源码调用 → 头文件/公开 API → 二进制符号/字符串 → 运行时/序列化/界面资源。
Model 额外检查 CodingKeys、JSON 映射、KVC/KVO、反射、归档兼容及服务端约定；方法检查 selector、delegate、协议默认实现和 target-action；文件检查 pbxproj、资源打包、脚本输入、动态加载和外部模块。
“本仓库未搜到”不等于无消费者。公开 SDK、反射使用和未扫描产物只能列为待核实，不能标“安全删除”。

输出表包含候选、文件/行号、搜索范围、支持/反对证据、风险、建议验证。明确哪些范围未检查。不自动删除、取消 target membership、运行清理脚本或提交。用户随后要求删除时，按确认清单逐项实施并编译/回归，保留兼容性考虑。
