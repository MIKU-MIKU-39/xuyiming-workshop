# 跨项目工具实施计划

维护者：Xuyiming。用户已于 2026-09-08 确认 docs/baitu-reuse-audit.md 的能力分组。

目标：在个人市场提供不依赖公司账号、固定工程路径或业务前缀的可安装工具。保留原发布插件和现有未提交改动，不自动提交/推送、安装全局 hook 或修改客户端配置。

架构：新增 ios-build / ios-quality / ios-diagnostics / tmp-guard / visual-patch 五个插件；扩展 dev-tools / lark-tools。各插件资源自包含，双端清单共享技能和脚本。脚本使用 Python 3.9+ 标准库，格式化和符号化按需调用项目已有工具。截图标注采用包内 HTML + Python localhost 服务，保留坐标/说明/验收条件 JSON 契约，不引入 Node 依赖。

## 文件与任务

1. 五个新插件 `.codex-plugin/plugin.json`、`.claude-plugin/plugin.json`、LICENSE、NOTICE、README：用官方脚手架登记 Codex，补 Claude 清单，保留上游归属。
2. `xym-ios-build/scripts/ios_build.py`、`proto_generate.py`：测试命令计划、Bundler 路由、目的地缺失、日志与退出状态；实现构建/查询/结果包装和显式 Proto 更新/生成。
3. `xym-ios-diagnostics/scripts/symbolicate.py`、`reference_scan.py`：测试 UUID/arch 歧义、源码/二进制来源和受限扫描；改编符号化脚本，编写引用采集；以 Skill 补复现和清理审计。
4. `xym-ios-quality/scripts/term_check.py`、`format_code.py`、`api_index.py`：先测试部分暂存读取、项目配置优先、格式预览、增量新增/修改/删除；实现词表与格式化入口、API 源码索引。词表来自用户配置，不带公司禁词。
5. `xym-tmp-guard/scripts/tmp_guard.py`：先测试专用根、归属标记、保留/完成状态、越界和符号链接；默认预览，只清理明确完成且属于本任务的目录，不靠时间自动删。
6. `xym-visual-patch/scripts/visual_patch.py`、`assets/index.html`：测试 token、固定路径、坐标/正文/请求大小、保存指针；实现本地标注和显式保存，不自动读剪贴板。
7. 开发 Skill：审查、简化、设计、提交和经验提炼；飞书：补 XML、reference-map 和周报局部更新流程，不发送真实远端写请求。
8. `tests/`：先验证核心失败路径，再逐个跑真实临时 Git / 本地 HTTP / 工具替身；可用时补最小本机工具冒烟。清单校验和 Skill 校验不能代替业务测试。
9. `README.md`、`docs/tool-extraction.md`：更新实际交付能力、依赖、安装状态、测试范围及未联调限制；完成后清理本任务临时校验依赖。

## 关键接口与错误约定

- Python CLI 返回 JSON 计划/结果；非法参数或依赖失败为非零，构建包装保留子进程退出状态。
- `--execute` 表示执行计划，不是用户授权来源；格式化默认仅 diff，临时清理默认只列目标。
- `term_check --staged` 读取 Git 索引 blob，读取失败和命中都不能报通过；词表匹配使用 literal/token/component 规则。
- 文档索引只输出候选声明与证据，最终公开 API 由源码/公开头文件/访问级别核实，不假装正则具备完整编译器语义。
- 临时目录 active/kept 不可清理；complete 后仍需显式执行 clean；未知路径或标记拒绝。
- 飞书和 GitHub 不自动重试不确定的写入。图像服务只绑定 loopback，写入固定项目目录，所有数据接口验证随机 token。

## 验收与提交边界

纯 Swift/SPM 与 CocoaPods/ObjC 项目形态、Unicode 路径、部分暂存、已有配置、缺失工具、失败退出码、隔离资源都须有行为验证。真实 iOS App、签名、账户/租户和具体业务回归只有实际运行才声称通过。提交/推送需用户另行授权，计划中的任务不自动产生 commit。
