# iPhone Duo 最小侵入适配技能

Created by Xuyiming on 2026/10/29.

## 背景与目标

用户已确认新增个人市场插件 xym-iphone-duo-adapt，验证后提交、推送并安装。本次产物是可复用技能，不是对某个业务工程执行适配。依据用户提供的 34 页 PPT、讲者备注、Apple 官方资料及本机 iPhoneSimulator27.1 SDK。

## 方案决策

采用短技能入口、按需读取的适配要点与回归协议、可复用验收记录。直接使用项目现有构建/测试设施和宿主子 Agent，不再开发构建包装器、截图服务器或业务适配框架。相比全局重构，局部修正尺寸来源、约束和受影响控件可保持原视觉；相比只写检查清单，每 1–3 页必须交给独立 reviewer 并保留截图/交互证据才可放行。

## 模块与接口

- SKILL.md：范围、批次门禁、完成条件。
- references/adaptation.md：容器、安全区、页面、列表、系统栏、ReservedRegion、视频/输入的最小改动选择。
- references/regression.md：真实模拟器矩阵、视觉比较、子 Agent 任务包与修复复验。
- references/sources.md：PPT 页码、官方链接、SDK 声明依据、非通用演示取值。
- assets/batch-review.md：批次证据记录模板，不把空模板当作通过记录。
- agents/openai.yaml、双端 plugin.json 和市场清单：可发现、可安装的 0.1.0 插件。

## 数据流与边界

目标工程/路径/构建环境明确 → 改前基线与页面清单 → 单批 1–3 页最小补丁 → 独立子 Agent 代码审核及 Duo/普通 iPhone 模拟器实测回归 → 只修本次适配问题并复验 → 放行下一批。

按 bounds/safe area/系统区域布局，不按机型推算尺寸。只在真实系统 API、版本、权限等边界校验，不加内部冗余防护。默认不换导航架构、播放器或设计语言，不迁移到分栏，也不附带业务修复。新 SDK 能力不等于自动提高最低系统版本；构建 SDK/工程配置变化须明确影响。

## 验收与失败处理

普通 iPhone 与改前同条件基线保持颜色、位置关系、间距、大小及圆角；Duo 可放宽可用画布和必要重排，不放宽遮挡、裁剪、不可点击。记录每台设备、运行时、姿态、构建、路由、数据/状态、前后截图及可操作性。无基线、无运行时、无权限或未进入页面记 blocked；不得用旧截图、静态审查或编译成功替代 UI 通过。

## 测试策略

验证插件双端结构、技能 frontmatter、引用完整性。使用独立子 Agent 对典型请求与有限证据进行前向试用，检查是否遵循批次门禁、识别越界改动和证据缺口。只读核实实际 Duo/普通 iPhone 模拟器能力；不把技能试用冒充业务 UI 实测。推送安装后比较源文件与缓存。
